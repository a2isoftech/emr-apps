The OnTrack App is a comprehensive solution designed to help dispatchers efficiently manage jobs and assets. It streamlines job allocation, tracks real-time asset locations, optimizes routes, and ensures timely deliveries, ultimately improving operational efficiency, reducing costs, and enhancing customer satisfaction.

## Features
- Manage Jobs
- Manage Assets
- Schedule Jobs
- Plan Jobs
- Manage Standing Orders
- View Reports
- View Customers

## Getting started
Make sure to have Flutter installed in your machine and web supported is enabled.
